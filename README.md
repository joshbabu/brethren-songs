# Kristhava Keerthanalu Netlify Sample

This is a sample Vite + React project for quick Netlify testing.

## Local run
1. npm install
2. npm run dev

## Netlify deploy
Build command: npm run build
Publish directory: dist

## Notes
- Tailwind is loaded via CDN for quick testing.
- Current content includes the full content index and songs 1 to 6.
- Add more songs in src/App.jsx inside the songs object.
